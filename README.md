# Titanic Dataset - Exploratory Data Analysis (EDA)

## Objective
Perform Exploratory Data Analysis (EDA) to understand the dataset using statistical summaries and visualizations.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly

## Tasks Performed
- Data loading and inspection
- Summary statistics generation
- Missing value analysis
- Histograms for numerical features
- Boxplots for outlier detection
- Correlation matrix visualization
- Pairplot analysis
- Survival analysis based on gender
- Interactive visualizations using Plotly

## Key Findings
- Most passengers were aged between 20 and 40 years.
- Female passengers had higher survival rates.
- Fare distribution contains significant outliers.
- Passenger class influenced survival chances.

## Dataset
Titanic Dataset (CSV)

## Output
Visualizations and statistical insights for understanding data patterns and relationships.
